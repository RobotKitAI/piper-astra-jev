# pipe-fitting

A 1-inch hex double pipe fitting in chrome-plated brass: male threads at both
ends, a hexagonal collar in the middle, a bore straight through. The working
mesh `pipe-fitting.stl` is in metres; `meta.json` has the measurements, the
frame (origin at the centre, z along the axis, x towards a hex corner) and the
symmetries (six-fold about z, end for end).

Generated from calliper measurements of the real part.
Run 7 uses it; `piper_llm/geometry.py` reads it.
